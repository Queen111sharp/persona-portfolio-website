# Personal Portfolio Website

A responsive personal portfolio website built with **HTML, CSS, and JavaScript**.

## About the project

This project was created for Week 1 Assignment 1: Build Your First Website Using AI. It introduces the owner, highlights technical skills, showcases sample projects, and provides contact information.

## Features

- Responsive layout for mobile, tablet, and desktop
- Home, About, Skills, Projects, and Contact sections
- Mobile navigation menu
- JavaScript-powered current year in the footer
- Separate HTML, CSS, and JavaScript files
- Personal profile photo

## Technologies

- HTML5
- CSS3
- JavaScript
- Git and GitHub

## Project structure

```text
portfolio-website/
├── index.html
├── style.css

└── .gitignore
```

## Getting started

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, `script.js`, and `profile.jpg` in the same folder.
3. Open `index.html` in a web browser.

No build tools or package installation are required.

## Customization

Before publishing, replace the sample content in `index.html`:

- Change `Your Name` to your name.
- Rewrite the introduction and About section.
- Add your real skills and projects.
- Replace `your.email@example.com` with your email address.
- Add links to your real project repositories where appropriate.

## AI tools used

ChatGPT was used as an AI assistant to help plan the page structure, generate an initial HTML/CSS/JavaScript implementation, and revise the homepage to display the supplied profile photo. The generated code should be reviewed, tested, and personalized before submission.

## Git workflow

This repository is used to demonstrate version control:

- `main` contains the stable portfolio.
- `feature/update-portfolio-content` is an example feature branch.
- Changes are committed in small, meaningful steps.
- A pull request is opened to review the feature branch before merging it into `main`.
